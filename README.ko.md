# docpin

**Claude Code용, 프로젝트 버전에 맞춘 라이브러리 문서 조회.**
웹 검색으로 페이지 전체를 읽는 대신, 에이전트가 원하는 내용이 *어디에* 있는지 찾아서
프로젝트가 실제로 쓰는 버전의 문서에서 그 구간만 가져옵니다.

인덱스는 문서를 복사한 것이 아니라 지도입니다. 페이지 경로, 제목, 섹션 제목,
앵커가 붙은 API 심볼, 그리고 몇 가지 키워드만 담습니다. 문서 본문은 저장하거나
재배포하지 않습니다.

> 이 문서는 영문 [README.md](README.md)의 번역입니다. 내용이 다르면 영문이 기준입니다.

## 언제 도움이 되나 (측정 결과)

같은 질문을 헤드리스 Claude Code에서 플러그인이 있을 때와 없을 때로 나눠
실행했습니다(Sonnet 5.5, 2026년 11월). 대상은 모델 학습 이후에 나온 Polars 2.0,
SQLAlchemy 2.1, Flet 1.0/1.1입니다. 문항은 튜닝이 끝난 뒤, 코드를 고칠 때 쓰지 않은
주제로 새로 만들었습니다. 정답은 공식 문서로 확인했고, 코드를 동결한 상태에서 문항마다
조건별로 두 번씩 실행했습니다.

| 검증 라운드 | docpin 있음 | 없음 (웹 검색) |
|---|---|---|
| **라운드 2** (12문항, 현재 코드) | 정답 **96%**, $0.072, 29초 | 75%, $0.080, 44초 |
| 라운드 1 (13문항, 변경 질문 개선 전) | 88%, $0.071, 29초 | 65%, $0.092, 56초 |

- **새 릴리스와 새 라이브러리:** 더 정확하고, 비용은 10~23% 적으며, 1.5~2배
  빠릅니다. 웹 검색은 업그레이드 가이드를 아예 못 찾고, 변경 내용이 없는 API
  페이지만 보고 "문서에 나와 있지 않다"고 답하는 경우가 많았습니다.
- **모델이 잘 아는 유명 라이브러리:** 비용은 비슷합니다. 플러그인이 방해가 되지는 않습니다.
- **모델이 외우고 있는 안정 API:** 에이전트를 부르지 않습니다.

한계: 표본이 작고, 모델 하나, PC 한 대(Windows)에서 측정했습니다.

## 동작 방식

```
질문 ─▶ Claude ─▶ doc-lookup 에이전트 (작은 모델, Bash와 WebFetch만 사용)
                     │ lookup.py <라이브러리> <검색어> --fetch 2   ← 호출 한 번
                     │   인덱스에서 페이지·심볼 순위를 매기고, lockfile로 버전을
                     │   고르고, 상위 2개 구간을 가져옴
                     ▼
                  출처 URL이 붙은 짧은 답 ─▶ Claude
```

- **페이지가 아니라 구간.** 맞는 제목이나 앵커 기준으로 페이지를 자르고(사이트가
  제공하면 markdown, 아니면 HTML) 크기 상한을 둡니다.
- **맞는 버전.** 버전은 `uv.lock`, `poetry.lock`, `requirements*.txt`,
  `package-lock.json`, `pnpm-lock.yaml`에서 가져옵니다. 그 버전이 인덱싱되어
  있지 않으면 추측하지 않고 그렇다고 알립니다.
- **변경 질문.** "2.1에서 뭐가 바뀌었어? X가 아직 있어?" 같은 질문은 그 버전의
  마이그레이션 노트와 changelog를 먼저 보여 줍니다.
- **정직한 "없음".** "인덱스에 없음"은 "기능이 없음"이 아닙니다. 예외는 그 버전에
  대해 전수 검증된 심볼 목록에서 정확한 심볼 이름을 찾지 못한 경우뿐입니다.
- **작고 분리된 컨텍스트.** 조회는 별도 에이전트에서 실행됩니다. 테스트에서 조회
  자체의 비용은 약 $0.002였습니다.

## 설치

Python 3.11 이상이 `PATH`에 있어야 합니다(`python`, Windows에서는 `py -3`도 됩니다).
스크립트는 표준 라이브러리만 사용합니다.

```bash
git clone https://github.com/dev-c2m/docpin.git
claude --plugin-dir ./docpin
```

그다음 어떤 언어로든 그냥 물어보면 됩니다: "Polars 2에서 explode()가 빈 리스트를 어떻게 처리해? 공식 문서 기준으로."

### 권한 설정

조회 한 번이 Bash 명령 하나입니다. 매번 권한 확인을 받지 않으려면 Claude Code
설정에서 아래 두 스크립트만 정확히 허용하세요(경로는 설치한 위치로 바꿉니다).

```json
{
  "permissions": {
    "allow": [
      "Bash(python \"/path/to/docpin/scripts/lookup.py\" *)",
      "Bash(python \"/path/to/docpin/scripts/fetch_section.py\" *)"
    ]
  }
}
```

`Bash(python *)`는 허용하지 마세요. 그러면 어떤 파이썬 코드든 실행할 수 있게 됩니다.

## 자주 쓰는 라이브러리 인덱싱

```
/index-docs pypi:mylib https://mylib.dev/docs/
```

지원 소스는 `llms.txt`, Sphinx/mkdocstrings `objects.inv`, `sitemap.xml`입니다.
LLM 없이 기계적으로 만들어서 비용이 들지 않습니다. 요청 간격을 두기 때문에 약 1,500페이지에
15분 정도 걸립니다. 버전별 문서는 버전과 URL 경로를 함께 지정합니다(예: `--ver 2 --ver-path latest`).

**비공개 문서:** 내 인덱스를 별도 폴더에 두고 플러그인 옵션 `index_path`로 지정하세요.
포함된 인덱스보다 우선 적용됩니다. 사내망 문서는 해당 인덱스의 `INDEX.md`에
`allow_private_network: true`를 설정합니다.

## 상태 표시

| 상태 | 의미 |
|---|---|
| `NO_INDEX` | 그 라이브러리의 인덱스가 없음. 에이전트가 웹으로 대신 확인 |
| `NO_MATCH` | 일치하는 항목 없음. 기능이 없다는 뜻이 **아님** |
| `NO_VERSION_INDEX` / `AMBIGUOUS_VERSION` | 쓰는 버전이 인덱싱되지 않았거나, lockfile끼리 버전이 다름 |
| `TRUNCATED` / `HEADING_MISSING` | 구간이 너무 길거나 페이지 구조가 바뀜. 제목 목록을 함께 보여 줌 |
| `DOMAIN_DENIED` / `REDIRECT→…` | 인덱스의 허용 도메인 밖이라 차단됨 |

## 한계

- 버전은 **메이저** 번호로만 구분합니다(SQLAlchemy 2.0과 2.1은 같은 항목이고,
  포함된 인덱스는 2.1입니다).
- `llms.txt`, `objects.inv`, `sitemap.xml`이 모두 없는 사이트는 아직 인덱싱할 수
  없습니다. JavaScript로만 렌더링되는 페이지는 읽을 수 없습니다.
- 로그인이 필요한 문서는 지원하지 않습니다.

## 개인정보와 보안

- 텔레메트리가 없습니다. 스크립트는 인덱스의 `allowed_domains`에 있는 호스트에만
  접속합니다. 다른 호스트로 가는 리다이렉트는 따라가지 않고, 사설·내부 주소는
  거부합니다(이를 허용한 비공개 인덱스는 예외).
- 인덱스 내용과 가져온 페이지는 지시가 아니라 데이터로만 다룹니다.
- 가져온 구간은 플러그인 데이터 폴더에 7일간 캐시됩니다.

보안 문제는 공개 이슈가 아니라
[GitHub 보안 권고(Security advisory)](https://github.com/dev-c2m/docpin/security/advisories/new)로
비공개 신고해 주세요.
