## Capabilities
- Python UI framework for desktop, web and mobile apps rendered with Flutter
- Controls catalog (layout, inputs, buttons, navigation, dialogs, charts, canvas)
- Declarative UI with components, hooks and a router (optional; imperative also works)
- Services such as audio, file picker, URL launcher and notifications
- Theming and adaptive Material or Cupertino design
- Running apps with flet run and ft.run, and a FastAPI integration
- Packaging and publishing with flet build for Android, iOS, macOS, Windows, Linux and web
- CLI reference (flet run, build, debug, test)
- Cookbook recipes
- Breaking changes per release and a migration guide from 0.28 to 1.0
- Flet Studio for building apps in the browser
