## Capabilities
- HTTP requests with GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS and custom verbs
- URL parameters, custom headers, form data and JSON request bodies
- Multipart file uploads, streaming uploads and chunk-encoded requests
- Response content as text, bytes, JSON, raw stream or iterated chunks
- Sessions that persist cookies and reuse connections (keep-alive)
- Timeouts, redirect history and typed exceptions for errors
- SSL certificate verification, CA bundles and client-side certificates
- HTTP and SOCKS proxies
- Authentication: Basic, Digest, netrc, OAuth 1 and custom auth classes
- Event hooks, transport adapters and automatic retries
- Prepared requests for low-level control of what is sent
