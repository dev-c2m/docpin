## Capabilities
- DataFrame, LazyFrame and Series with an expression API (select, with_columns, filter)
- Lazy queries with query optimization and a streaming engine for larger-than-memory data
- Group by aggregations, window functions and folds
- Joins and reshaping of data frames
- Strings, lists and arrays, structs, categoricals and enums
- Missing data handling and type casting
- User-defined Python functions with map_elements and map_batches
- IO: CSV, Parquet, JSON, Excel, databases, cloud storage, Hive partitions, Hugging Face
- SQL interface over data frames
- GPU execution (open beta)
- Upgrade guides listing breaking changes for each major version, including 2.0
