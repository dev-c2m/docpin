## Capabilities
- Data validation and parsing with models defined by type hints (BaseModel)
- Fields with defaults, aliases and constraints
- Field-level and model-level custom validators
- Serialization to dict and JSON with include and exclude controls
- JSON Schema generation from models
- Strict mode and documented type conversion rules
- Standard and custom types, including unions
- Validating dataclasses and arbitrary types with TypeAdapter
- Validating function arguments with the validation decorator
- Model configuration via ConfigDict
- Settings management from environment variables (pydantic-settings)
- Performance tips and forward annotations
