## Capabilities
- ORM declarative mapping with type-annotated Mapped columns and relationships
- Session and unit-of-work persistence, loading strategies and loader options
- Core SQL expression language: select, insert, update, delete
- Schema definition with Table and MetaData, DDL including CREATE VIEW (2.1)
- Engine configuration and connection pooling via create_engine
- asyncio support with AsyncEngine and AsyncSession (asyncio extra)
- Reflection of existing database schemas
- Event hooks for Core and ORM
- Custom types and type decorators
- Dataclass and attrs integration for ORM classes
- Dialects: PostgreSQL, MySQL and MariaDB, SQLite, Oracle, SQL Server
- Migration notes and changelogs for every release series
